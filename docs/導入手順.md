# 導入手順（GASエディタでの操作）

「GAS（Google Apps Script）エディタ」は、ブラウザ上でプログラムを置いて実行する Google の画面です。
ここに `src/` のファイルを貼り付け、初期設定用のプログラム `setup` を **1回だけ** 実行します。

---

## 手順1 GASプロジェクトを作る

1. ブラウザで https://script.google.com を開く（保存先フォルダにアクセスできるアカウントでログイン）。
2. 左上の「**新しいプロジェクト**」を押す。
3. 左上の「無題のプロジェクト」をクリックし、名前を `SVレポート登録` に変更する。

## 手順2 ファイルを貼り付ける

エディタ左側の「ファイル」欄にファイルを作り、リポジトリの `src/` の中身をそれぞれ貼り付けます。

### スクリプト（.gs）… 1ファイルだけ

1. 最初からある `コード.gs` を開き、中身を**すべて削除**する。
2. リポジトリの **`dist/SVレポート登録.gs`** の中身を**すべて**コピーして貼り付ける（9本のスクリプトを1つにまとめたもの、約1200行）。
   - **確実に全文をコピーする方法**: ブラウザで https://github.com/eisuke1101/svreport_registration/blob/claude/upbeat-heisenberg-w10cr4/dist/SVレポート登録.gs を開き、ファイル表示の右上にある「**Copy raw file**」（重なった四角のアイコン）を押す。
     チャットやプレビュー画面からのコピーは、途中までしかコピーされないことがあります。
   - 貼り付け後、エディタの**最終行**が `// ===== ファイル終端（全○○行）: この行まで貼り付けられていればOK =====` になっていて、行番号がその行数と一致することを確認する。
3. 他に `.gs` ファイルを作っている場合は削除する（同じ関数が2つあるとエラーや誤動作の原因になります。ファイル名の右の「︙」→「削除」）。

### 画面（.html）

**＋** →「**HTML**」で作成。名前は **`index`、`css`、`js`**（`.html` は不要）。それぞれ `src/index.html`、`src/css.html`、`src/js.html` を貼り付ける（上と同じく GitHub の「Copy raw file」でコピー。例: https://github.com/eisuke1101/svreport_registration/blob/claude/upbeat-heisenberg-w10cr4/src/js.html ）。
`js.html` は最終行が `</script>` になっていることを確認する。

### 設定ファイル（appsscript.json）

1. 左端の歯車「**プロジェクトの設定**」を開く。
2. 「**「appsscript.json」マニフェスト ファイルをエディタで表示する**」にチェック。
3. エディタに戻ると `appsscript.json` が表示されるので、中身を `src/appsscript.json` で置き換える。
   （これで Drive API の有効化・タイムゾーン・権限の設定が反映されます）

> appsscript.json の置き換えをしなかった場合は、代わりに次の2つを行ってください。
> - エディタ左の「**サービス**」の **＋** →「**Drive API**」→ バージョン **v3**、ID「**Drive**」のまま「**追加**」
> - 「プロジェクトの設定」の「**タイムゾーン**」を **(GMT+09:00) 東京** にする

貼り付け後、**Ctrl + S**（Mac は ⌘ + S）で保存。

## 手順3 テンプレートExcelをGoogleドライブに置く

1. `SVレポート_2026.10ver.xls` を Google ドライブにアップロード（保存先フォルダの中でも、別の場所でもよい）。
2. アップロードしたファイルを右クリック →「共有」→「**リンクをコピー**」。
3. コピーしたURLの `https://drive.google.com/file/d/` **〜** `/view` の間の文字列がファイルIDです。

   例: `https://drive.google.com/file/d/1AbCdEfGhIjK.../view?usp=sharing` → `1AbCdEfGhIjK...`

## 手順4 スクリプトプロパティを設定する

1. 歯車「**プロジェクトの設定**」を開き、一番下の「**スクリプト プロパティ**」→「**スクリプト プロパティを追加**」。
2. 次を入力して「**スクリプト プロパティを保存**」。

| プロパティ | 値 |
|---|---|
| `TEMPLATE_XLS_FILE_ID` | 手順3のファイルID（必須） |
| `NOTIFY_TO` | 登録通知の送信先メールアドレス |

保存先フォルダは指定済み（`1fCaEEFJMTKgGPPINg7G5TuBNuohbwymo`）なので設定不要です。

## 手順5 `setup` を実行する（← README の「エディタで setup を実行」）

1. 左端の「**エディタ**」（`< >` アイコン）に戻り、ファイル一覧から **`Setup.gs`** を開く。
2. 画面上部のツールバーに、関数を選ぶプルダウンがあります（「実行」「デバッグ」ボタンの右）。ここで **`setup`** を選ぶ。
3. **「▷ 実行」** を押す。
4. 初回は権限の確認画面が出ます。
   1. 「権限を確認」→ 自分のアカウントを選択。
   2. 「このアプリは Google で確認されていません」と表示された場合は、左下の「**詳細**」→「**SVレポート登録（安全ではないページ）に移動**」。
      （自分で作ったスクリプトなので問題ありません）
   3. 「**許可**」を押す（ドライブ・スプレッドシート・メール送信の権限）。
5. 画面下の「実行ログ」に **「実行完了」** と、`セットアップ完了` に続けて「管理DB」と「テンプレート」のURLが出れば成功です。

### setup で作られるもの

保存先フォルダの中に `_システム` フォルダができ、次の2つが入ります。

- `SVレポート_テンプレート` … Excel を Google スプレッドシートに変換したもの（登録時にこれをコピーしてレポートを作る）
- `SVレポート_管理DB` … 校舎マスタ・項目マスタ・登録履歴・明細・写真・取込ログ のシート

setup は何度実行しても大丈夫です（作成済みのものは作り直しません）。

### よくあるエラー

| 表示 | 対処 |
|---|---|
| `TEMPLATE_XLS_FILE_ID に…設定してください` | 手順4のプロパティ名・値を確認 |
| `SyntaxError: Unexpected end of input` | 貼り付けが途中で切れている。最終行の「ファイル終端」の目印を確認し、「Copy raw file」でコピーし直す |
| `props_ is not defined` などの `… is not defined` | スクリプトの貼り付け漏れ、または未保存。`dist/SVレポート登録.gs` を全文貼り付けて保存し直す |
| `実施日の形式が不正です: undefined` など | 実行プルダウンで `setup` 以外の関数が選ばれている。`setup` を選び直して実行 |
| `Drive is not defined` / `Drive API（拡張サービス）が有効になっていません` | エディタ左の「サービス」の **＋** →「**Drive API**」→ バージョン v3・ID「Drive」のまま「追加」。その後 setup を再実行 |
| `Exception: …アクセス権がありません` / `見つかりません` | 実行しているアカウントが保存先フォルダ・テンプレートを編集できるか確認 |

## 手順6 項目マスタを確認する

`SVレポート_管理DB` を開き「項目マスタ」シートの「**対象外業態**」列に、業態ごとに対象外の項目を入力（例: `アスモ`、複数は `アスモ,すみれ`）。
「アスモは対象外」と書かれた No.59 は自動で入っています。

## 手順7 ウェブアプリとして公開する

1. 右上の「**デプロイ**」→「**新しいデプロイ**」。
2. 「種類の選択」の歯車 →「**ウェブアプリ**」。
3. 設定:
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: 担当者全員が会社の Google Workspace アカウントなら「**（組織名）内の全員**」、個人の Gmail の人がいるなら「**Google アカウントを持つ全員**」
4. 「**デプロイ**」→ 表示された「**ウェブアプリのURL**」を担当者に共有。

プログラムを修正したときは「デプロイ」→「**デプロイを管理**」→ 鉛筆アイコン → バージョン「新バージョン」→「デプロイ」で反映します（URLは変わりません）。

## 手順8 PDF出力メニューを使う

`setup` を実行すると、管理DBにメニュー「**SVレポート**」が追加されます（管理DBを開き直すと表示）。

- **PDF出力（未出力をすべて）**: 「登録履歴」シートの「PDF出力」列が空欄の行をすべてPDFにします。
- **PDF出力（選択した行）**: 「登録履歴」シートで出力したい行を選択してから実行します（行番号をクリックして選択。Ctrl/⌘ を押しながらで複数選択可）。

PDFは `{年度}年度/第{回}回/PDF/` に保存され、「PDF出力」列に「済」が入ります。
初めてメニューを使うときは権限の確認画面が出るので、setup のときと同じ手順で許可してください。
他の担当者がメニューを使う場合は、そのアカウントにこの GAS プロジェクトの閲覧権限（共有）が必要です。

### 機能追加後のコード更新（PDF出力を追加したとき）

1. `コード.gs` の中身を全部消し、最新の `dist/SVレポート登録.gs` を「Copy raw file」でコピーして貼り付け、保存（最終行の「ファイル終端」の目印を確認）。
2. appsscript.json を置き換えている場合は、最新の `src/appsscript.json` に置き換えて保存。
3. 実行プルダウンで **`setup`** を選び ▷実行 → 権限の確認画面で「許可」（外部サービスへの接続・トリガー・メニュー表示の権限が追加されています）。
4. 管理DBを開き直し、メニュー「SVレポート」が出ることを確認。
5. ウェブアプリにも修正を反映する場合は「デプロイを管理」から新バージョンをデプロイ。
